# UI 视觉验收记录

更新日期：2026-07-31

本文只记录当前有效的验收结论。历史问题截图与中间产物位于本地
`qa/`，不进入最小交付包，避免后续 AI 把已修复问题误判为当前状态。

## 验收基线

- 主设计分辨率：1920×1080
- 验收分辨率：仅 1920×1080
- 默认主题：亮色
- 可选主题：暗色（设置 → 外观设置）
- 性能档位：低性能 / 普通（默认） / 流畅
- 地图区域：主页主要交互区域，约占左上内容区 64%
- 跟随距离：0.5–10.0 m，步进 0.1 m
- 底部导航：自绘主题图标，亮暗主题均可见

## 已确认项目

- 首页“控制模式”总卡片中的四个等高入口（导航、语音、手柄、视觉控制）、设置、点位管理、机器人状态、视觉跟随、语音控制、
  声纹管理及全屏地图使用统一主题和组件。
- 主页不存在旧版粗黑框、多层卡片和超大按钮。
- 车辆状态使用上位机、下位机、运行与连接三列，不保留装饰车辆示意。
- 地图、快捷操作和状态信息的层级清楚，空白比例合理。
- 视觉和语音详情均替换右半屏，左侧地图与车辆状态保持可见；退出后 Loader 销毁详情实例。
- 启动页在上次主题对应的纯白/纯黑背景上显示两方 Logo、`&`、系统名称和加载动画。
- 全屏地图默认完整显示，支持点选、鼠标/单指拖动、滚轮/双指缩放，以及车头朝上自动居中。
- 手柄教程包含 9 步高亮和纯 QML 动作示意，不调用真实车辆控制。
- 亮色与暗色主题的文字、状态色和底部导航图标可读。
- 现有 QML → `UiBackend` → `RobotApiBase` 调用边界保持不变。
- 低性能档取消装饰动画并降低刷新频率；流畅档增加轻量页面、弹窗、轮播和控件过渡。
- 二级页返回后销毁；首页视觉跟随半全屏使用 Loader 按需创建，退出后摄像头控制实例立即销毁；隐藏首页图片停止解码；软键盘常驻但默认隐藏，显式按钮可反复显示和隐藏。
- 地图管理页沿用现有卡片和按钮体系；PGM 轮播最多创建三个预览对象，
  分档轻量位移/缩放/透明度动画不使用 ShaderEffect。

## 自动验证

在项目根目录执行：

```bash
source .venv/bin/activate
python -m pytest -q
```

界面启动及 QML 日志检查：

```bash
QT_QPA_PLATFORM=wayland python main.py
```

若没有 Wayland：

```bash
QT_QPA_PLATFORM=xcb python main.py
```

## 人工回归清单

1. 切换亮色/暗色并逐页检查文字与图标。
2. 在 1920×1080 下分别检查小/标准/大字体和细/中/粗边框。
3. 检查返回、主页、全屏、设置及弹窗关闭路径。
4. 检查点位选择、导航、回充、跟随和语音相关按钮仍调用原接口。
5. 检查跟随距离滑块端点为 0.5 m 和 10.0 m。
6. 连接真实 ROS 2 后再验收地图、状态与动作结果；Mock 模式不能替代实车验收。
7. 三档逐一切换并重启，确认设置持久化；低性能无装饰动画，流畅切页和轮播无卡顿。
8. 反复进入/退出地图、设置、声纹和跟随页面，确认内存不持续增长。
9. 在全屏地图拖动或缩放后点选目标，确认坐标换算仍正确；开启朝向模式后车辆保持居中。
10. 从建图提示进入手柄教程，完成或跳过后确认建图提示重新出现。
